Businesses

One document per lending company. Every record that belongs to a business carries its businessId. Loan It Financing is seeded and all 57 existing records sit under it.

Users

pid, email, role, businessId, name, phone, TRN, address, status, createdAt, lastLoginAt, profileCompletedAt.

lastLoginAt is a real timestamp. The collection currently holds free text like “Today, 10:20 AM”, which can’t be sorted or reported on. On first sign-in, anyone without profileCompletedAt is held in a modal that collects their details before the app opens — one component, every role, so staff and customers get the same experience.

Migration order

Additive first, enforcing second, so nothing breaks halfway.

  1. Create businesses, seed Loan It Financing, backfill businessId onto every existing record. Done.
  2. Resolve roles from the users table, keeping the env bootstrap. Done.
  3. Only then filter every query by businessId.

The CRM

01

The ticket thread building now

  • tickets — pid, businessId, subject, status (open / waiting on customer / resolved), priority, customer, assignedTo, createdAt, lastReplyAt
  • about — a link to the contract, standing order, salary deduction or application the ticket concerns, so support opens it already knowing the case
  • tickets/{id}/messages — author side, body, timestamp
  • An admin list in the same table / ⋮ menu / detail modal pattern as the rest of the admin
  • A customer page to raise a ticket and follow the thread

Working the queue

Assignment to a person, status transitions with timestamps, internal notes the customer never sees, and filters for “mine” and “unassigned”.

03

Customer view

One page per customer pulling together their applications, authorization forms, contracts, loans, payments and tickets — the thing support actually wants open while talking to someone.

First-response and resolution timers, breach flags, and ticket counts on the admin dashboard alongside the loan figures.

The licence details are not confirmed

TAJ does not license or list lenders — the Bank of Jamaica does, under the Microcredit Act, 2021.

BOJ’s published list cannot settle the question either way. Pulling the page’s full stored content through the WordPress API returns ten institutions, nothing hidden behind pagination, and no “Loan It” — but the page carries a modified date of 12 September 2023. It has not been touched in three years; JIS reported thirteen licensed institutions as far back as May 2023, so the list was already incomplete then, and a licence numbered MCA-016-2025 would postdate the page entirely. Absence from that list is not evidence of anything.

The business record therefore carries licenceVerified: false, which means “not yet confirmed” — not “not licensed”. The licence number and legal name should be set from the licence document itself, because MCA-016-2025 is printed on the loan agreement above the borrower’s signature.
